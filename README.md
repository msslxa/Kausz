# Kausz
Birational geometry of Kausz compactification

This repository contains Maple worksheets used to reproduce the polyhedral cone computations appearing in the paper for the varieties TL_n

Eff_Mov.mw
implements the degree (divisor) matrix for the Cox ring. Using Maple’s polyhedral-cone routines (positive hulls, intersections, rays), it computes: the effective cone and the movable cone.

Eff_Nef_and_Duals.mw
extends the previous computations to the nef cone, the Mori cone of effective curves, and the cone of moving curves.
